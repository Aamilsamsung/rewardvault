# RewardVault

A secure rewards and redemption platform built with Next.js and Supabase.

## Roadmap
- Responsive premium rewards dashboard, user profile, offers and wallet
- Supabase Auth, Postgres schema and row-level security
- Atomic points ledger, verified reward grants and idempotent redemptions
- Admin catalog and redemption approvals
- Provider-backed payouts only after funded, authorized integration

## Deployment
Deploy on Vercel with environment variables configured in project settings. Never commit provider secrets or Supabase service-role keys.

**Status:** project initialized; real redemption providers and deployment are not yet configured.
